PN independent wide-Zeny client - 28 September 2026

Install together with the matching PN server maintenance release. The server
wallet and account bank each support 9,223,372,036,854,775,807 Zeny. Each character
keeps a separate wallet; the bank is shared by characters on that account.

Open Wallet & Bank with the bank button, @bank, Ctrl+B or Alt+B. Use direct
Deposit/Withdraw, +100K/+1M/+10M/+100M/+1B/+10B/Max, or Collect offline Zeny.
Collect moves offline character wallets to the shared account bank. Saving
status is pending; only a confirmed server receipt means the save completed.

Use the companion Trade, Market and Mail controls for full-width Zeny values.
Start player trades in the game, review native item lists, then set and lock the
exact Zeny offer in Wallet & Bank. Confirm both offers explicitly. Create a
native vending/buying draft, open Market, set exact prices and buying budget,
review and Publish. Search and purchases use exact prices and confirmation.
The server saves both players and market stock together before completion.
Market checks pending status without automatically resending a purchase.
Mail supports Zeny-only composition with an exact fee/debit preview; item-bearing
and received mail remain in RODEX. Refresh after connection loss to check status.

The normal game Zeny display now shows the confirmed full wallet balance,
up to 9,223,372,036,854,775,807, with the matching native-HUD server update.
Weight and Zeny appear on separate right-aligned lines in Basic Information.
Other legacy numeric displays and inputs retain their original limits.
Use the companion controls for larger transactions; the server rejects
unsafe legacy transaction values. The Ragexe executable remains unchanged.
This client provides the PN features documented in this release.

Diamonds and 1M tickets are retired. Maintenance converts existing currency
holdings into account-bank Zeny: 499,000,000 per 17carat diamond and 998,000 per
1M Zeny Ticket. Guild storage credits its leader; mailed currency credits the
recipient. The conversion preserves value at these stated redemption rates.
Exchange controls are removed and retired tokens cannot create new currency.
